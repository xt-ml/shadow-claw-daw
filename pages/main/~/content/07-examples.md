## Song Showcase & Programmatic Examples

Every ShadowClaw DAW arrangement is plain JSON compressed with raw DEFLATE (`deflate-raw`) and encoded into a URL `#file=` hash fragment. That means complete multi-track songs—instruments, SoundFont GM programs, effects, time signatures, and MIDI notes—live inside a single self-contained hyperlink with zero backend storage required.

Click any public-domain arrangement below to open it directly in the workbench, inspect its tracks and score, remix its instruments, or press Play right away.

### Generating Shareable Song Links with Python (Zero Dependencies)

You do not need an open browser tab or external packages to compose a full ShadowClaw DAW song. Using only Python's standard library (`json`, `zlib`, `base64`), you can construct a Schema v2 project dictionary, compress it with **raw DEFLATE** (`wbits=-15` matching browser `CompressionStream("deflate-raw")`), strip `=` padding from URL-safe Base64, and print a ready-to-play `#file=` link.

Below is the exact pipeline used to generate these links, demonstrated with an 8-bar public-domain arrangement of **Mary Had a Little Lamb** in C major (`4/4`, `108 BPM`):

```python
import json
import zlib
import base64

# Ticks per quarter note:
# PPQN = 960 pulses per quarter note.
# In 4/4, 4 quarter notes * 960 pulses = 3840 pulses per bar.
# In 3/4, 3 quarter notes * 960 pulses = 2880 pulses per bar.
# In 6/8, 6 eighth notes * 480 pulses = 2880 pulses per bar.

Q = 960  # quarter note
H = 1920 # half note
E = 480  # eighth note

# Public-domain 8-bar "Mary Had a Little Lamb" in C major (C4 = 60, D4 = 62, E4 = 64, G4 = 67)
melody_pitches = [
    (64, Q), (62, Q), (60, Q), (62, Q),
    (64, Q), (64, Q), (64, H),
    (62, Q), (62, Q), (62, H),
    (64, Q), (67, Q), (67, H),
    (64, Q), (62, Q), (60, Q), (62, Q),
    (64, Q), (64, Q), (64, Q), (64, Q),
    (62, Q), (62, Q), (64, Q), (62, Q),
    (60, H * 2),
]

melody_notes = []
pos = 0
for pitch, dur in melody_pitches:
    melody_notes.append({
        "position": pos,
        "duration": int(dur * 0.9),
        "pitch": pitch,
        "velocity": 0.85
    })
    pos += dur

# Simple harmonic bass accompaniment (G2 = 43, C3 = 48, D3 = 50, G3 = 55)
bass_chords = [
    (48, H), (55, H),
    (48, H), (55, H),
    (43, H), (50, H),
    (48, H), (55, H),
    (48, H), (55, H),
    (48, H), (55, H),
    (43, H), (50, H),
    (48, H * 2),
]

bass_notes = []
bpos = 0
for pitch, dur in bass_chords:
    bass_notes.append({
        "position": bpos,
        "duration": int(dur * 0.95),
        "pitch": pitch,
        "velocity": 0.75
    })
    bpos += dur

data = {
    "version": 2,
    "name": "Mary Had a Little Lamb",
    "bpm": 108,
    "signature": [4, 4],
    "lengthBars": 8,
    "swing": 0,
    "metronome": {"enabled": False, "volume": 0.8},
    "master": {"volume": 0.5},
    "midiMappings": [],
    "tracks": [
        {
            "id": "trk_mary_melody",
            "name": "Melody",
            "kind": "synth",
            "volume": 0.9,
            "pan": -0.1,
            "mute": False,
            "solo": False,
            "recordArm": False,
            "midiInput": {"deviceId": None, "channel": "omni", "enabled": True},
            "midiOutput": {"deviceId": None, "channel": 1, "enabled": False},
            "params": {
                "waveform": "triangle",
                "cutoff": 1200,
                "resonance": 2,
                "attack": 0.01,
                "decay": 0.2,
                "sustain": 0.5,
                "release": 0.2,
                "program": 0
            },
            "notes": melody_notes,
            "audioClips": [],
            "automation": {},
            "sends": [],
            "instrument": "soundfont",
            "fx": [
                {"id": "fx_mary_rev1", "type": "reverb", "decay": 1.5, "damping": 0.5, "preDelayMs": 8, "wet": 0.2}
            ],
            "color": "#80d4db",
            "channelRole": "regular",
            "midiFx": []
        },
        {
            "id": "trk_mary_bass",
            "name": "Accompaniment",
            "kind": "synth",
            "volume": 0.75,
            "pan": 0.1,
            "mute": False,
            "solo": False,
            "recordArm": False,
            "midiInput": {"deviceId": None, "channel": "omni", "enabled": True},
            "midiOutput": {"deviceId": None, "channel": 1, "enabled": False},
            "params": {
                "waveform": "sine",
                "cutoff": 800,
                "resonance": 1,
                "attack": 0.02,
                "decay": 0.3,
                "sustain": 0.6,
                "release": 0.3,
                "program": 0
            },
            "notes": bass_notes,
            "audioClips": [],
            "automation": {},
            "sends": [],
            "instrument": "soundfont",
            "fx": [
                {"id": "fx_mary_rev2", "type": "reverb", "decay": 1.5, "damping": 0.5, "preDelayMs": 8, "wet": 0.15}
            ],
            "color": "#f4a261",

            "midiFx": []
        }
    ],

    "sections": [],
    "meta": {
        "title": "Mary Had a Little Lamb",
        "artist": "ShadowClaw",

url = f"https://xt-ml.github.io/shadow-claw-daw/#file={encoded}&autoplay=true"
print(url)
```

### How AI Agents Can Generate Music Programmatically

Agents have two complementary paths for composing music in ShadowClaw DAW:

1. **Headless Python URL Generation (No Active Tab Required)**
   - Works in any shell, sandbox, or CLI workflow (`python3`) without waiting on a browser `BroadcastChannel` tab.
   - **Step 1 — Author the Schema v2 JSON**: Define `bpm` (`20–300`), `signature` (e.g., `[4, 4]`, `[3, 4]`, `[6, 8]`), `lengthBars`, `tempoMap`, `signatureMap`, and `tracks`.
   - **Step 2 — Compress with Raw DEFLATE (`wbits=-15`)**: Always pass `wbits=-15` (omits the zlib header/trailer so it matches browser `CompressionStream("deflate-raw")`) and compact JSON separators `(',', ':')`.
   - **Step 3 — Encode & Validate**: Base64URL-encode without trailing `=` padding, verify round-trip decompression (`zlib.decompress(base64.urlsafe_b64decode(pad), -15)`), and keep the final `#file=` URL within `65536` characters (`MAX_HASH_URL_LENGTH`).
   - **Step 4 — Deliver Playable Link**: Append `&autoplay=true` so the user hears the song right after clicking **Load Song from URL**.

2. **Live Workbench Control (Browser WebMCP Tools)**
   - When the workbench tab is open at [`/main/`](https://xt-ml.github.io/shadow-claw-daw/main/), agents can call `scdaw_compose_song` (high-level `SongSpec` compiler with bar/beat strings), `scdaw_write_notes`, `scdaw_set_instrument`, `scdaw_apply_preset`, `scdaw_manage_fx`, or invoke skills such as `/song`, `/beat`, `/jam`, and `/soundfont-orchestra`.
