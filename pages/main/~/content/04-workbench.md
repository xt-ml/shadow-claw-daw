## Interactive Workbench UI

Accessible directly at `/pages/main/index.html` (`/main/`):

- **Main Shell (`<shadow-claw-daw-workbench>`)**: Integrated studio docking workbench featuring collapsible dock toggles (`📁 Browser`, `🎛 Studio`, `🎛 Mixer`), full-width focus views (`📁 Browser (Full)`, `🎚 Mixer (Full)`, `🎹 Piano Roll (Full)`, `🥁 Drum Matrix (Full)`, `🎛️ Synth (Full)`, `🌊 Audio (Full)`), dedicated distraction-free **Full Screen Focus Mode** (`⛶ Full Screen` / `✕ Exit Full Screen` with <kbd>Escape</kbd> shortcut, native Fullscreen API support, and CSS in-window fixed overlay fallback), an in-studio Detail Editor Switcher (`🎹 Piano Roll`, `🥁 Step Sequencer`, `🎛️ Synth`, `🎛️ Device Rack`, `🌊 Audio`), a dismissible ARIA `role="alert"` `#scdaw-error-banner` surfacing runtime errors, accessible `<shadow-claw-dialog>` confirmation modals, OPFS Save/Export and keyboard-navigable Open/Import dialogs, **compressed URL song sharing** (`🔗 Press a URL` modal generating `#file=` shareable links with length pre-validation, `?file=`/`#file=` startup loading, and `?autoplay=true` automatic playback), collapsible `<shadow-claw-daw-midi-keyboard>` dock with safe QWERTY keyboard routing, context-sensitive drag-and-drop import, lossless Undo history, and instant offline WAV bouncing.
- **Transport Bar (`<shadow-claw-daw-transport>`)**: Mobile-first **Play/Pause** toggle (`▶ Play` / `⏸ Pause`) with playhead resume and dedicated **Stop** rewind button, **Record** control with native modal `<dialog id="scdaw-error-dialog" closedby="any">` error surfacing (`NotFoundError`, `NotAllowedError`, `NotReadableError`, etc.) and recovery guidance, Audio Metronome toggle (`🔔 Metro`) with downbeat-accented rhythmic click synthesis and instant stopped audition feedback, Start Audio unlock button, LCD musical position readout (`Bar : Beat : 16th`), touch/pointer drag up/down & wheel-adjustable `20–300` BPM tempo controls (with Shift fine-tuning), interactive **time signature** (`4/4`, `3/4`, `6/8`, `12/8`, `9/8`, `2/4`, `2/2`, `5/4`, `7/8`, `3/8`) and **bar length** (`lengthBars`) controls with auto-expand, swing groove slider, **Web MIDI status & configuration** button (`🎹`) opening the MIDI Learn dialog (live MIDI monitor, per-port toggles, Soft Takeover, controller presets with 8-channel bank paging, JSON mapping export/import, and MIDI Learn creator), right-click `contextmenu` MIDI Learn on transport buttons/BPM/swing, MIDI capture commit badge, and Panic (`All Notes Off`) button.
- **Library Browser (`<shadow-claw-daw-browser>`)**: Left-hand library dock with categorized tabs for Presets, Devices (Instruments, Audio FX, MIDI FX), Conversation Files (OPFS), and All items with instant search filtering, drag-and-drop payload support, and one-click track loading.
- **Arrangement Timeline (`<shadow-claw-daw-timeline>`)**: Multi-track timeline view with measure ruler and **pointer/touch playhead ruler scrubbing** (`calculateTimelineSeekPpqn`), sticky track headers with Mute, Solo, and Record Arm controls (`aria-pressed` + right-click `contextmenu` MIDI Learn and live `liveRevision` sync), click-to-select track synchronization across the studio, **Project Label Track** lane (`+ Label`, click/Enter to seek, Delete/Backspace/`×` to remove), **audio clip fade-in/fade-out ARIA slider handles**, SVG fade & gain envelope overlays, keyboard `S` (split), `D` (duplicate), and `M` (mute) clip shortcuts, **drag-and-drop audio import** (`.wav`, `.mp3`, `.ogg`, `.flac`) onto audio lanes, **balanced left and right gutters** (`--timeline-gutter-l`, `--timeline-gutter-r`) providing hit target separation from split-pane resize handles, **magnetic audio clip snapping** (`🧲 Beat` / `Bar` / `Off`), and **mobile-first track re-ordering** with `⋮⋮` grab handles (`touch-action: none`, pointer capture, keyboard arrows) alongside `▲`/`▼` 1-tap touch nudge buttons.
- **Audio Waveform & Spectrogram Editor (`<shadow-claw-daw-wave-editor>`)**: Mobile-first interactive audio clip workstation (`🌊 Audio` Studio tab and `🌊 Audio (Full)` view) featuring stacked responsive toolbars (`< 640px`) and `@container` enhancements (`>= 640px`), interactive time-range selection with `ZC Snap` zero-crossing alignment (`Z`), per-clip gain envelope point editing (drag-eat/restore control point semantics), `Waveform` / `Spectrogram` / `Split View` modes with `roseus`/`classic`/`grayscale`/`inverseGrayscale` palettes and `linear`/`logarithmic`/`mel` scales, drag-and-drop audio file import onto `#wave-stage`, audio generators (`Tone`, `Noise`, `DTMF`, `Silence`), non-destructive edit actions (`Split`, `Split Silences`, `Trim`, `Silence`, `Duplicate`, `Mute`, `+ Label`), and lossless offline DSP actions (`Normalize`, `Loudness` LUFS, `Amplify +3dB`, `Remove DC`, `Reverse`, `Invert`, `De-Click`, `Fade In`, `Fade Out`, `Bake Fades`, `Truncate Silence`, `Tempo +10%`, `Pitch +2st`, `Speed +10%`, `Get Noise Profile`, `Reduce Noise`).
- **Plot Spectrum Analyzer (`<shadow-claw-daw-spectrum>`)**: Embedded or standalone calibrated FFT power-spectrum viewer (`📊 Spectrum` toggle in `<shadow-claw-daw-wave-editor>`) with configurable FFT size (`256–8192`), 6 window functions, linear/logarithmic frequency axis toggle, and live peak frequency / dBFS / musical pitch note cursor readout.
- **Note Editor & Piano Roll (`<shadow-claw-daw-editor>`)**: 2D chromatic piano roll editor with sticky piano key labels (`role="button"`, `Enter`/`Space`, click/tap, and pointer/touch **drag-glissando auditioning** with `touch-action: none`, `aria-pressed` feedback, and click deduplication), octave/pitch grid with `bar-start` markers, `role="button"` cells with `Enter`/`Space`/Arrow-key navigation, O(N) pre-indexed active cell rendering for zero-pause live note edits, **note auditioning on add**, scroll-position preservation, interactive velocity lane (`role="slider"` stalks), chord insertion shortcut, and a responsive Note Inspector.
- **Pattern Step Sequencer (`<shadow-claw-daw-sequencer>`)**: 16-step drum and synth matrix sequencer with event delegation, keyboard-accessible `role="button"` cells (`Enter`/`Space`/ArrowLeft/ArrowRight), `bar-start` markers, in-place step sync, **note auditioning on step add**, step-memory preservation, and active playhead tracking.
- **Synthesizer Workbench (`<shadow-claw-daw-synth>`)**: Dedicated full-width or in-studio synthesizer workstation exposing all parameters for `Vaporisateur`, `Tubular` (true 6-operator / 32-algorithm DX7 FM with interactive algorithm SVG topology, Bessel `PeriodicWave` self-feedback, per-operator `OP1–OP6` cards, and `.syx` single/32-voice cartridge import/export), `PSG` (YM2149/AY-3-8910 chiptune engine), `Cubed` (303), `808`, `Pluck`, `Neon`, `Korpus`, `Noise Pad`, `Nano`, and `SoundFont`, paired with a live `AnalyserNode` oscilloscope, ADSR curve display, per-step parameter locks, right-click `contextmenu` MIDI Learn, and immediate `liveRevision` knob redraw.
- **Device Rack Inspector (`<shadow-claw-daw-devices>`)**: Modular horizontal device rack synchronized to the selected track, displaying its MIDI FX, Instrument voice engine, and Audio FX chain with `<shadow-claw-daw-knob>` rotary controls, live parameter modulation without audio graph rebuilds, right-click `contextmenu` MIDI Learn, immediate `liveRevision` knob redraw, device reset actions, and touch overscroll containment.
- **Mixer Console (`<shadow-claw-daw-mixer>`)**: Multi-channel mixing console with pointer-captured vertical faders (supporting drag, mouse wheel, and double-click reset), `<shadow-claw-daw-knob>` stereo pan controls, zero-zipper live parameter ramping (`setTargetAtTime`), `🎯 Learn` toggle mode and right-click `contextmenu` MIDI Learn across channel and master controls, 14-segment peak/clipping LED meters, track selection highlighting, mute/solo/reset actions, and master output strip.
- **Software MIDI Keyboard (`<shadow-claw-daw-midi-keyboard>`)**: Accessible, mobile-first on-screen and QWERTY software MIDI keyboard supporting multi-touch pointer play and **drag-glissando** across keys, toggleable **Ableton** (`A–'`, `Z`/`X` or `-`/`=` octave) and **2-Octave Tracker** (`Z–M` / `Q–U`, `-`/`=` or `[`/`]` octave) computer keyboard layouts (`#layout-btn`), on-key QWERTY keycap badges (`aria-keyshortcuts`), reactive octave/layout sync, **Hold**, **Sustain** (`CC64`), octave/velocity controls, and real-time 3D depressed key feedback.
- **Rotary Parameter Knob (`<shadow-claw-daw-knob>`)**: High-precision rotary control supporting linear and exponential scaling, mouse/touch drag, mouse wheel adjustment, WCAG 2.1 AA `role="slider"` keyboard navigation, and double-click default restore.
- **Split-Pane Resize Handle (`<shadow-claw-daw-resize-handle>`)**: Accessible, touch-friendly vertical panel splitter supporting pointer-captured dragging, `invert` direction awareness for right-hand docks, keyboard adjustment via Arrow keys, and WCAG 2.1 AA `role="separator"` ARIA telemetry.
- **Status Bar (`<shadow-claw-daw-status-bar>`)**: Responsive bottom telemetry strip displaying audio context state, project summary (`Name · BPM · Tracks`), Web MIDI port/activity status, bounce telemetry, active error badge (`#error-stat`), and leader lock status.

### Responsive Design, BEM & Accessibility

All components use strict BEM naming and declare `container-type: inline-size;` with `@container` queries and `@supports not (container-type: inline-size)` fallbacks:

- **Mobile First (`< 640px`)**: Single-column stacked layout with responsive toolbar button grids wrapping cleanly without scrollbars or overlapping buttons, touch-friendly horizontal scroll containers (`overscroll-behavior-x: contain`), and sticky track/key headers.
- **Multi-Pane Studio Layout (`>= 640px` & `>= 1024px`)**: Resizable 3-column CSS Grid studio arrangement (`Browser` | `<shadow-claw-daw-resize-handle>` | `Center Stack` | `<shadow-claw-daw-resize-handle>` | `Mixer`) where either side dock can be independently toggled while keeping the Timeline, Detail Editor, and Device Rack centered.
- **Full-Width Focus Modes, Coarse Touch Targets & Fullscreen Viewport**: Instant 100%-width workspace expansion for `📁 Browser (Full)`, `🎚 Mixer (Full)`, `🎹 Piano Roll (Full)`, `🥁 Drum Matrix (Full)`, `🎛️ Synth (Full)`, and `🌊 Audio (Full)`, automatically hiding inactive docks and resize splitters via `.hidden` / `[hidden]`, paired with `@media (pointer: coarse)` 44×44px minimum touch target sizing and native modal `<dialog>` accessibility.
